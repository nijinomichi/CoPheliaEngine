# Contributing to CoPhelia³ Engine

Thank you for helping grow the failure-loving ecosystem.

## Ways to contribute

1. **Share anonymized failure logs**  
   Add entries to (or PR against) the RadicanTrust™ schema style in `failure_log_sample.json`.  
   Keep personal data out. Focus on the creative friction that later became fuel.

2. **Improve the core engine**  
   - Better vectorization / embedding of failure text  
   - Additional PT-symmetric or φ-based transforms  
   - Visualization helpers (Golden Spiral, phase portraits)

3. **Docs, examples, translations**  
   Japanese / English / other language READMEs and notebooks welcome.

4. **Downstream modules**  
   VRChat worlds, Stable Diffusion / ComfyUI nodes, HCI experiment scripts, etc.

## Pull Request guidelines

- One focused change per PR when possible.
- Include a short note on *why* the change helps the “failure → φ” loop.
- If you add a new dependency, justify it (we aim to stay minimal: numpy + scipy).
- For failure logs: use the sample schema, mark `"anonymous": true`.

## Code of Conduct (short)

We celebrate constructive failure. No shaming of past attempts.  
Be kind to humans and to the models that learn from us.
